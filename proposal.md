# Fish Tank Aquraium

## Repository
(https://github.com/joyOxO/proposal)

## Description
A Fish Tank that is interactive, it will be like an interactive drawing. I believe it would be considered digital art.
## Features
- Feature 1: Fish Swimming
	- I will use methods similar to the make it rain with trail possibly.
- Feature 2: Click Fish to Make them swim away fast.
	- I will use the same base code I used for my make it rain with key commands with pygame to make them swim away quickly with a speed multiplyer.
- Feature 3: Random Fish Appearance
	- Using random

## Challenges
- Importing/Generating Pixel Art.
- Pixel Art Animation.
- Possible Day and Night Cycle? (Lights in Background)

## Outcomes
Ideal Outcome:
- A Randomized Fish Tank inspired by Fish Tank Lamps, the fish will be interactable everything will be made with pixel art and there will be bubbles moving in the background as well.

Minimal Viable Outcome:
- Background is visible, Fish move and are Interactable, Bubbles Appear.
